# Ashit Mahesh Vachhani: portfolio

I turn manual workflows into AI-powered automations.

Live site: https://ashitvachhani.github.io

## How this site is organized

| File | What it holds | How often it changes |
|---|---|---|
| `data.js` | Featured case studies, the archive, and the hours-saved figure behind the live counter | Whenever a project is added or updated |
| `index.html` | Layout, styling, the intro, the persona chooser, and the four visitor paths | Rarely |

## Adding a project

- **Featured case study:** add an entry to `cases` in `data.js` (title, one-liner, impact, problem, steps, flow, why it works).
- **Smaller build:** add an entry to `archive` in `data.js` (title, one-liner, status `live` / `retired` / `proto`, optional impact).

The "N more builds" count on the Hiring manager path updates automatically.

## Direct links

Each visitor path has its own link: `#recruiter`, `#manager`, `#builder`, `#curious`.
